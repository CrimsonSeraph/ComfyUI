# 启动快捷键与常用界面快捷键

本文件记录两类内容：

1. **启动快捷键** —— 给 ComfyUI 启动器做桌面快捷方式、绑全局快捷键、固定到任务栏；
2. **界面快捷键** —— ComfyUI 画布内的常用操作。

---

## 一、启动快捷键

### 1. 创建桌面快捷方式

1. 右键 `.\custom\launcher\start-comfyui.bat` → **发送到 → 桌面快捷方式**；
2. 右键新建的快捷方式 → **属性**，按下表设置：

| 选项卡 | 字段 | 建议值 | 说明 |
| --- | --- | --- | --- |
| 快捷方式 | 目标 | `.\custom\launcher\start-comfyui.bat` | 保持默认即可 |
| 快捷方式 | 起始位置 | `.\` | 留空也能工作（脚本自己推导仓库路径） |
| 快捷方式 | 运行方式 | **最小化** | 隐藏入口控制台；后端窗口仍会正常弹出并显示日志 |
| 快捷方式 | 快捷键 | 例如 `Ctrl + Alt + C` | 点进输入框后**直接按组合键**，不能手打 |
| 快捷方式 | 更改图标 | 见下方"图标" | 可选 |
| 兼容性 | 以管理员身份运行 | **不要勾选** | ComfyUI 不需要管理员权限 |

> 填写时使用完整路径
> **快捷键只对放在桌面或开始菜单里的快捷方式生效**。放在普通文件夹里的快捷方式无法用快捷键唤起。
> 若 `Ctrl+Alt+C` 被占用（有些截图/输入法工具会占用），换 `Ctrl+Alt+Shift+C` 之类。

### 2. 图标（可选）

快捷方式默认显示 bat 的齿轮图标，可改成更好认的：

- 用 Edge 图标：`%ProgramFiles(x86)%\Microsoft\Edge\Application\msedge.exe`（在"更改图标"里粘贴此路径）；
- 或用系统图标库：`%SystemRoot%\System32\shell32.dll`，再选一个（如索引 137 的齿轮/应用图标）；

### 3. 固定到任务栏 / 开始菜单

- 右键桌面快捷方式 → **固定到任务栏**（或 **固定到"开始"屏幕**）；
- 任务栏上的图标单击即可启动，等价于双击 bat。

### 4. 带参数的快捷方式（可选）

想用固定参数启动，可在快捷方式"目标"里追加，或先设环境变量。
因为环境变量不能直接写在"目标"里，推荐两种做法：

**做法 A —— 用 `cmd /c` 包一层（写进"目标"）**：

```bat
REM 使用完整路径
cmd /c "set COMFY_NO_PULL=1 && .\custom\launcher\start-comfyui.bat"
```

**做法 B —— 多个快捷方式对应多种模式**（推荐，最直观）：

| 快捷方式名 | 目标写法 | 用途 |
| --- | --- | --- |
| ComfyUI（日常） | `...\start-comfyui.bat` | 拉取更新 + 启动 |
| ComfyUI（快速） | `cmd /c "set COMFY_NO_PULL=1 && set COMFY_NO_INSTALL=1 && ...\start-comfyui.bat"` | 跳过更新，秒启 |
| ComfyUI（仅更新） | `cmd /c "set COMFY_NO_START=1 && ...\start-comfyui.bat"` | 只同步代码与依赖，不占显存 |
| ComfyUI（备用端口） | `cmd /c "set COMFY_PORT=8189 && ...\start-comfyui.bat"` | 8188 被占用时 |

> 完整环境变量清单见 [`launcher/README.md`](launcher/README.md)。

### 5. 开机自启（可选）

把上面第 1 步的快捷方式放进启动文件夹：
`Win + R` → 输入 `shell:startup` → 回车 → 把快捷方式拖进去。
建议用"快速"模式（`COMFY_NO_PULL=1`）以免每次开机都等拉取。

## 二、界面快捷键

以下为 ComfyUI 画布内的常用快捷键（macOS 用户把 `Ctrl` 换成 `Cmd`）。

### 运行

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `Enter` | 把当前图加入生成队列 |
| `Ctrl` + `Shift` + `Enter` | 把当前图作为队列**第一个**生成 |
| `Ctrl` + `Alt` + `Enter` | 取消当前生成 |

### 编辑

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `Z` / `Ctrl` + `Y` | 撤销 / 重做 |
| `Ctrl` + `C` / `Ctrl` + `V` | 复制粘贴选中的节点 |
| `Ctrl` + `C` / `Ctrl` + `Shift` + `V` | 复制粘贴并保持与未选中节点输出端的连线 |
| `Delete` / `Backspace` | 删除选中节点 |
| `Ctrl` + `Backspace` | 删除当前整张图 |
| `Ctrl` + `A` | 全选节点 |
| `Ctrl` + `/` `Shift` + `Click` | 追加选中节点 |
| `Ctrl` + `M` | 静音 / 取消静音选中节点 |
| `Ctrl` + `B` | 旁路（bypass）选中节点，相当于移除该节点并把线接过去 |
| `Alt` + `C` | 折叠 / 展开选中节点 |
| `Ctrl` + `G` | 把选中节点打组 |
| `P` | 固定 / 取消固定选中节点 |
| `Shift` + `Drag` | 同时移动多个选中节点 |
| `Shift` + `Drag`（从连线起） | 一次拖动多根连线 |
| `Ctrl` + `Alt` + 左键点插槽 | 断开该插槽上的所有连线 |

### 视图与面板

| 快捷键 | 作用 |
| --- | --- |
| `空格` + 拖动 | 平移画布 |
| `Alt` + `+` / `Alt` + `-` | 画布放大 / 缩小 |
| `Ctrl` + `Shift` + 左键纵向拖动 | 连续缩放画布 |
| `.` | 缩放到选中节点（未选中时缩放到整张图） |
| `双击左键` | 打开节点快速搜索面板 |
| `Q` | 显示 / 隐藏队列 |
| `H` | 显示 / 隐藏历史 |
| `R` | 刷新画布 |
| `F` | 显示 / 隐藏菜单 |
| `Ctrl` + `S` / `Ctrl` + `O` | 保存 / 加载工作流 |
| `Ctrl` + `D` | 加载默认工作流 |

### 与启动器相关的两个操作

| 操作 | 说明 |
| --- | --- |
| 关闭 **ComfyUI backend** 控制台窗口 | 停止 ComfyUI 服务（等价于 Ctrl+C） |
| 关闭 Edge 应用窗口 | **不**停止服务；重新双击启动器会在端口已监听时直接重新打开窗口 |
